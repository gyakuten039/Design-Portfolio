📌 核心工作流程说明：
① 纯文字问答：用户输入 → 微信云开发内置AI（文心一言ERNIE-3.5）→ 流式输出回答
② 图片识别：选择图片 + 输入问题 → 上传云存储获取临时URL → recognizeImage云函数 → 豆包视觉模型分析 → 返回识别内容
③ 文生剪纸：先生成文字 → 点击「生成剪纸图案」→ generateImage云函数 → 豆包Seedream生图 → 展示剪纸图片
④ 图生剪纸：选择已有图片 → 点击「图生图」→ 上传原图 → generateImage(img2img模式) → 基于原图生成剪纸风格新图
⑤ @剪纸AI触发：在任意评论/对话场景中 @剪纸AI + 问题 → 系统自动判断类型（文字/图片）→ 调用对应AI模型 → 返回结果
